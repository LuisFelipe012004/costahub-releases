# CostaHUB — instaladores

Instaladores do aplicativo desktop do **CostaHUB** (gestão da oficina Costa Parts).

- Baixe o `CostaHUB_x.y.z_x64-setup.exe` da [última versão](../../releases/latest) e instale uma vez em cada computador.
- Depois disso o app **se atualiza sozinho**: ao abrir, ele avisa quando há versão nova e pergunta se quer atualizar.
- Cada pacote é assinado digitalmente; o app recusa instaladores adulterados.

Este repositório contém apenas os instaladores publicados automaticamente. O código-fonte é privado.
